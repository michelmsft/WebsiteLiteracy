# Create your GitHub account

GitHub stores the website files and their change history. You create your account now. Codex creates the website's repository later, so you don't need to set up project folders yourself.

A **repository** is a project folder that records saved changes. The **main branch** is the saved version that the publishing workflow follows.

| Component | What you're trying to achieve |
| --- | --- |
| GitHub account | Let Codex save and publish your project with your approval |
| Repository, created later by Codex | Store the website and automatic deployment instructions |

This exercise should take approximately **10** minutes to complete.

## Prerequisites

You need a browser and an email address you control. Use an existing personal GitHub account if you already have one.

## Create the free account

You register for GitHub Free. No paid plan is needed.

1. Open [GitHub signup](https://github.com/signup).
1. Follow the prompts to choose a username and create your account.
1. Complete the requested account and email verification.
1. Stay on the free plan if a plan selection appears.
1. Sign in at [GitHub](https://github.com).
1. Confirm that your profile menu shows your username.

**What you should see:** Your signed-in GitHub account. Don't create a repository yet.

## Protect your account

You add a second sign-in check before authorizing a tool to use GitHub.

1. Open your profile menu and select **Settings**.
1. Open **Password and authentication**.
1. Set up two-factor authentication with one of GitHub's supported methods.
1. Save recovery codes somewhere secure outside GitHub.

> **Important**: The course uses a public repository for free standard GitHub Actions runs. Everyone can read its files. Use fictional website content, not customer information or company secrets.

## Summary

You have successfully completed this exercise. Codex can now ask you to sign in to GitHub and create your website repository.

## Clean up

No repository or cloud resource is created. Keep the account if you plan to continue. You don't need to delete the account when you finish the course.
